过渡金属与配位化学：中部的彩色腰带

红宝石的红是铬、翡翠的绿也是铬；蓝色硫酸铜、黄色铁锈、紫色高锰酸钾、你血管里运氧的血红素—— 周期表中部那条宽宽的 d 区腰带，承包了自然界大半的颜色与生命过程的关键反应。 本章先看 d 区金属的三大招牌（多变价、彩色化合物、好催化），再学一套全新语言—— 配合物：中心离子、配体、配位数；最后用晶体场理论的"d 轨道分裂"一步看懂： 为什么无色的离子一遇到配体，就染上鲜艳的颜色。

导入：颜料店的一半货架

走进一间颜料店：群青、钴蓝、铬绿、镉红、铁黄……数一数标签上的元素，大半来自周期表中部 第 3–12 列。这条"腰带"里的元素被称为过渡金属 transition metals——"过渡"指的是它们的性质在活泼的 s 区金属与 p 区之间过渡，也指它们的电子正在逐个填充次外层的 d 轨道（回忆第 1 章 §1 的思考题： 4s 填完才轮到 3d，d 电子"住在里层却中途加入"）。

正是这批"住在里层"的 d 电子，给了过渡金属三件法宝：多种氧化态、缤纷的颜色、卓越的催化能力。 而要真正读懂颜色，我们还得先学一门新的"分子语法"——配位化学。它研究的对象 配合物coordination complex长得像句套娃： 一个金属离子坐在中央，一圈分子或离子手拉手围着它。别小看这种结构—— 血红素、叶绿素、维生素 B12，全是配合物。

§1 d 区三大招牌：多变价、彩色、好催化

招牌一：多变价。主族金属通常只有一种"体面"的价态（Na⁺、Mg²⁺、Al³⁺）， 过渡金属却像换衣服一样自然：铁有 Fe²⁺/Fe³⁺，铜有 Cu⁺/Cu²⁺，锰更是从 +2 一路演到 +7 （KMnO4 里的 Mn 就是 +7）。原因正是那批 d 电子：次外层 d 与最外层 s 能量相近， 化学反应里两层电子都能参战——少给几个、多给几个，都不伤元气。

招牌二：彩色化合物。d 区溶液是化学实验室最上镜的部分，一张表认识常客：

物种颜色备注
Cu2+（水合）蓝色§3 的主角
Fe2+ / Fe3+浅绿 / 黄色同一元素两种脸色
Co2+ / Ni2+粉红 / 绿色变色硅胶里的钴会"报湿度"
MnO4−紫色（浓艳）颜色来自电荷迁移，见 §3
CrO42− / Cr2O72−黄色 / 橙色酸碱度切换两种脸

招牌三：好催化。多变的价态让过渡金属可以"先接盘、再交货"： 铁催化剂帮 N2 和 H2 分步合成氨（哈伯法，喂饱了全球一半人口）； V2O5 在接触法制硫酸中来回复价；汽车尾气净化里的 Pt、Pd 把 CO 与 NO 转成无害气体；你身体里几乎每一种酶的活性中心都坐着一种过渡金属。 能伸出 d 轨道拉一把反应物、再全身而退——这是催化者的天赋。

想一想：为什么主族金属很少"多价"，过渡金属却动辄五六个价态？

提示：回忆第 1 章——Na 失去最外层 1 个电子后就剩下什么结构？再打破它容易吗？

Na 失去 3s 电子后是满壳的 Ne 结构，再要动第 2 层电子，电离能陡增一个数量级——所以主族"一价定终身"。 过渡金属不同：反应时先丢 ns，剩下的 (n−1)d 电子彼此能量接近、逐个可丢， 丢 2 个、3 个……成本是"缓坡"而非"悬崖"。价态多 = 氧化还原角色多 = 催化的资本， 三大招牌其实是同一件事（d 电子位置灵活）的三张面孔。

§2 配合物的组成、结构与命名

往硫酸铜溶液里滴氨水，除了颜色变化，还发生了一件更本质的事：氨分子用氮原子上的 孤对电子lone pair抓住了 Cu²⁺，形成了一种 "金属离子 + 环绕分子"的新物种。这类结构叫配合物（也叫配位化合物），它的三要素：

  • 中心离子（或原子）：坐镇中央的金属，如 Cu²⁺、Fe³⁺——提供空轨道的"房客"；
  • 配体（ligand）：围着中心的路由器，如 H2O、NH3、CN⁻—— 直接与中心结合的原子叫配位原子（NH3 是 N，CN⁻ 是 C）；
  • 配位数：直接与中心结合的配位原子数，常见 4（平面正方形/四面体）与 6（八面体）。

配体与中心之间的化学键叫配位键coordinate bond： 共用电子对完全由配体一方提供，中心离子只出空轨道。本质仍是共价键，只是"出资方"单边。 注意这句话的方向——配体出电子对，是"给电子的行家"；中心离子接受电子对。这条伏笔在 第 4 章会正式展开成路易斯酸碱理论。

内界、外界与命名入门

写配合物化学式时用方括号圈出"内界"（靠配位键抱团的核心），括号外是"外界"（靠离子键松散搭伙）。 例如 [Cu(NH3)4]SO4：内界 [Cu(NH3)4]2+ + 外界 SO42−。溶于水时外界解离， 内界基本原样不动——所以溶液显示的是配合物自己的颜色。

命名只要记一个模板：（配体数 + 配体名 + "合" + 中心离子名 + 括号内罗马数字氧化态）， 阴离子配合物再缀一个"酸"。两个例子走一遍：

  • [Cu(NH3)4]SO4 → 硫酸四氨合铜(Ⅱ)（外界酸根名在前，四氨 = 4 个 NH3，铜的氧化态 Ⅱ）；
  • K3[Fe(CN)6] → 六氰合铁(Ⅲ)酸钾（内界是阴离子，命名末尾加"酸"，铁的氧化态 Ⅲ）。
例 1 · 完整示范（看我做）：拆解 K₃[Fe(CN)₆]
指出 K3[Fe(CN)6] 的内界与外界、中心离子及其氧化态、配体与配位原子、配位数，并命名。
  1. 找括号：方括号内 [Fe(CN)6]3− 是内界；括号外 3 个 K+ 是外界。外界电荷与内界相反、总量相等 → 内界带 −3。
  2. 定中心氧化态：内界里 6 个 CN− 共 −6，内界净电荷 −3，设铁为 x：x + (−6) = −3 → x = +3，中心是 Fe³⁺。
  3. 认配体：配体是氰根 CN−，配位原子是碳 C（孤对电子在 C 端），每个 CN⁻ 提供 1 个配位原子。
  4. 数配位数：6 个 CN⁻ 各出 1 个 C → 配位数 = 6，几何为八面体。
  5. ✅ 命名：内界为阴离子 → 末尾加"酸"：六氰合铁(Ⅲ)酸钾。自查：外界 3 个 K+(+3) 与内界 −3 恰好中和，整个化合物电中性 ✓

想一想：CO 一不带电、二不显碱性，凭什么也能当配体？——煤气中毒的化学就在这一问

提示：配体的入场券不是电荷，而是孤对电子。CO 的碳端有吗？

有，而且极强。CO 的碳端孤对电子不仅能配位，还能反过来接受金属的 d 电子（"反馈键"）， 与血红素里 Fe²⁺ 的结合力是 O2 的 200 倍以上——这就是煤气中毒的原理： CO 霸占了运氧座位，氧气排队进不来。急救的关键是高压氧舱用高分压把 CO 顶下去。 配体竞争的胜负，常常就是孤对电子"出手"的强弱——记住这个画面，第 4 章的酸碱争夺战你会再次见到它。

§3 晶体场初步：d 轨道分裂出颜色

一切颜色的源头是一个几何问题。自由金属离子的 5 个 d 轨道（dxy、dxz、dyz、 dz²、dx²−y²）能量完全相同；但当 6 个配体从六个方向逼近（八面体构型）， 指向配体的两个轨道（dz²、dx²−y²，合称 eg）迎头撞上负电云，能量被顶高； 避开配体的三个（dxy 等，合称 t2g）相对落低——这就是 d 轨道分裂d-orbital splitting， 两组之间的能量差记作 Δo（分裂能）。

🪜 三级阶梯 · 无色的离子，配上配体怎么就有颜色了？
LEVEL 1 · 类比

把白光想成一整排琴键。普通的自由离子像一台没调过音的琴——键与键之间没有音差， 任何可见光都"弹不动"它，所以无色。配体一来，像有人垫高了其中两个键： 出现了固定的音差。恰好等于这个音差的光会被吸收（弹响）， 白光里少了一段颜色，你眼睛看到的就是剩下的互补色。音差（Δ）由配体决定—— 换配体，就是重新调琴。

LEVEL 2 · d-d 跃迁

说回电子：配体场把 5 个 d 轨道劈成高 (eg) 低 (t2g) 两组，能差 Δ。 Cu²⁺（d⁹）的电子可以吸收能量恰好等于 Δ 的光子，从低组跳到高组——这就是 d-d 跃迁d-d transition。白光扫过去， 被吸收的波段消失，溶液就呈现出被吃掉颜色的互补色。水合铜离子的 Δ 对应吸收橙红光 → 你看到蓝色； 换成 NH3 配体，Δ 变大，吸收向短波移动，溶液常呈深蓝；不能仅由 Δ 推断颜色深浅。

LEVEL 3 · 定量与例外

光子能量 E = hν = hc/λ：Δ 越大，吸收波长越短，观察色随互补关系移动。 配体强弱排序（光谱化学序列片段）H2O < NH3 < CN− 中，CN− 之所以最强，除静电外还能用 π 体系分走金属 d 电子（反馈），进一步拉大分裂。 两个重要例外要记：① d 轨道全满或全空（如 Zn²⁺ d¹⁰、Sc³⁺ d⁰）不能发生 d-d 跃迁；没有其他可见光吸收时通常无色； ② MnO4−（Mn +7，d⁰）却浓紫——那不是 d-d 跃迁，而是更强的"电荷迁移"（O 的电子瞬时跳向 Mn）， 吸收强度比 d-d 高百倍，颜色也浓艳得多。

⚠️ 误区粉碎机 · "物质的颜色来自添加的颜料"
✗
误区 蓝色瓶子装着蓝色染料，绿色溶液掺了绿色颜料——硫酸铜溶液那么蓝，一定是溶了什么"铜颜料"进去。
✓
正确 过渡金属溶液的颜色不需要任何颜料：d 电子按 Δ 吸收可见光的特定波段（d-d 跃迁）， 剩下的光进入你的眼睛——颜色是选择性吸收的负片（互补色）。Cu²⁺ 吸橙红显蓝、 Fe³⁺ 吸紫蓝显黄、MnO4− 吸黄绿显紫。证据是加了配体后颜色随 Δ 变化而变—— 如果只是"掺颜料"，换配体不该换颜色。
⚠️ 误区粉碎机 · "滴了氨水颜色变深，只是浓度变大了吧"
✗
误区 淡蓝变深蓝嘛，跟冲浓咖啡一个道理——氨水只是把 Cu²⁺"浓缩"了，铜离子还是那个铜离子。
✓
正确 变的是化学物种本身：配体从 H2O 换成了 NH3， [Cu(H2O)4]2+ → [Cu(NH3)4]2+。 NH3 的配体场更强 → Δ 更大 → 吸收峰向短波移动。实际色调与色深要结合完整吸收光谱判断。 下面的模拟器让这场"换座位"全程可见——还能用稀盐酸把它请回原座。

想一想：Zn²⁺ 也能与 NH₃ 形成配合物 [Zn(NH₃)₄]²⁺，为什么它的溶液几乎无色？

提示：数一数 Zn 原子的 d 电子数（Zn 是 30 号，Ar 核 + 3d¹⁰4s²）。

Zn²⁺ 是 d¹⁰ 全满：低组轨道全部占满、高组也全占——电子没有可去的高组空位， d-d 跃迁无从发生，可见光基本不被吸收，溶液无色。同理 Sc³⁺（d⁰）没有电子可跳， 也无色。反过来说，颜色本身就泄露了 d 电子的填充情况：d 介于 0 和 10 之间，才有"舞台"可跳。 这就是为什么"有色"成了 d 区的招牌，而 s 区、锌族例外地素颜。

🧯 氰化物安全警告（必读）
本节的 CN⁻ 只是纸上谈兵——任何含氰化物的实验都严禁自行尝试。 CN⁻ 的配位能力极强，进入体内会死死结合细胞色素氧化酶里的 Fe³⁺，呼吸链当场瘫痪， 数毫克即可致命；遇酸还放出剧毒的 HCN 气体。工业上含氰废水必须先氧化解毒再排放。 "配位能力最强"在试管里是漂亮的蓝色，在身体里是致命的抢劫——化学的威力从来双向。
模型边界与参考

本章配位图只突出赤道平面的四个配体，轴向水配体未画出； 水合铜离子通常写作 [Cu(H₂O)₆]²⁺，过量氨水中的主要深蓝物种写作 [Cu(NH₃)₄(H₂O)₂]²⁺。 Δ 决定简化模型的吸收能量，不能单独决定色深。参见 英国皇家化学会：配体交换与铜配合物。

🧺 本章小结

  • 过渡金属三大招牌同源：d 电子能量灵活 → 多变价（Mn 可达 +7）、彩色（d-d 跃迁）、好催化（合成氨、尾气净化、酶活性中心）。
  • 配合物三要素：中心离子（出空轨道）、配体（出孤对电子）、配位数（常见 4 平面正方形、6 八面体）；配位键是"单边出资"的共价键。
  • 方括号内是内界（配位键抱团），外是外界；命名模板"配体数 + 配体名 + 合 + 中心名(氧化态)"，阴离子内界加"酸"。
  • 晶体场初步：配体把 5 个 d 轨道劈成两组，能差 Δ；电子吸收能量恰为 Δ 的可见光跃迁（d-d），呈被吸收色的互补色。
  • 配体强度片段 H2O < NH3 < CN−：换配体 → 换 Δ → 换颜色；d⁰/d¹⁰ 无色；MnO4− 的浓紫来自更强的电荷迁移。
  • CO 中毒与氰化物中毒都是配体竞争抢占 Fe 位点——配位化学直接关乎生死。

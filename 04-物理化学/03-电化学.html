电化学：化学能与电能的兑换所

手机电量从 100% 掉到 20%，你的一天就开始焦虑。这块小小的电池里， 正上演着第一章和第二章的合奏：电子转移（氧化还原）提供能量差， 而一套精巧的装置让电子不再"就地"传递，而是沿着导线定向流动—— 那就是电流。本章从一枚 1836 年的铜锌电池讲起：盐桥为什么必不可少？ 电极电势如何预判反应方向？电解为什么能"逆天改命"？最后看看锂离子电池里 Li⁺ 如何像摇椅一样荡来荡去。

导入：把"火"装进盒子里

人类用火几十万年：木柴氧化，放出光和热——但能量四散奔逃，抓不住、带不走。 1800 年伏打把铜片和锌片叠进盐水里，第一次让氧化还原安静地发生在金属表面， 电子被导线收拢成电流。从此，"燃烧"被装进了盒子：汽车引擎里烧汽油是化学能→热能→机械能， 而氢燃料电池车里同样的氢氧反应直接给出电流，效率翻倍、尾气只剩水。

电化学研究的就是化学能 ⇌ 电能的双向兑换：自发的反应（ΔG < 0）可做成电池发电； 不自发的反应（ΔG > 0）可用电解强行推动。本章的路线：先复习电子记账（§1）， 再拆解原电池（§2），学会用电势表预判方向（§3），然后用它反向做功（§4）， 最后走进你口袋里的锂电池（§5）。

§1 氧化还原：电子的会计学

氧化数oxidation number是给原子分配的"电子账面值"。 反应中氧化数升高 = 失电子 = 被氧化（该物质是还原剂，替别人出电子）； 氧化数降低 = 得电子 = 被还原（该物质是氧化剂，收别人的电子）。 电子不会凭空消失：有人失就有人得，两本账必须轧平。

看本章的主角反应：把锌片插进蓝色的硫酸铜溶液，锌表面慢慢镀出红棕色铜，溶液蓝色褪去：

Zn + Cu2+ → Zn2+ + Cu 　　Zn：0 → +2（失 2e⁻，被氧化）　Cu：+2 → 0（得 2e⁻，被还原）

直接混合时，电子在锌铜接触面上"就地"转移，能量以热的形式散掉。 电化学的全部智慧，就是让氧化和还原在两个地点分别发生，逼电子沿导线绕行—— 于是散逸的能量变成了可利用的电流。

想一想：把铁钉和铜丝同时浸入稀盐酸，只在铁钉表面冒出气泡。谁在失电子？铜在干什么？

提示：冒出的气泡是 H₂，H⁺ 得电子被还原；那么电子是谁给的？

铁失电子：Fe − 2e⁻ → Fe²⁺，放出的电子被表面的 H⁺ 接走，生成 H₂ 气泡。 铜不与稀盐酸反应——它失电子比铁"不情愿"得多。这种失电子难易的差异， 正是 §3 电极电势要定量刻画的东西，也是 §2 里锌愿做负极、铜只做正极的原因。

§2 原电池：拆开一场氧化还原

1836 年丹尼尔把上面的反应拆成两半：锌片插进 ZnSO₄ 溶液（左），铜片插进 CuSO₄ 溶液（右）， 两杯溶液之间架一支盐桥，金属片之间接上导线——灯亮了。这套装置叫 原电池galvanic / voltaic cell， 每半套叫一个半电池half-cell。电极命名是本章第一道坎：

电极发生的反应电子走向丹尼尔电池中
负极 = 阳极氧化（失电子）电子流出，经外电路去正极Zn 电极：Zn − 2e⁻ → Zn²⁺
正极 = 阴极还原（得电子）接受外电路流入的电子Cu 电极：Cu²⁺ + 2e⁻ → Cu
📌 记忆锚点
阳—氧押韵，负极唱氧化：阳极永远发生氧化反应（"阳氧"），阴极永远发生还原反应（"阴还"）。 至于阳极是不是"正极"，原电池与电解池恰好相反——§4 会专门拆这个坑。

🪜 三级阶梯 · 盐桥到底解决什么问题？
LEVEL 1 · 类比

想象一条搬运队往仓库搬货：只管往里搬、不管往外清，门口很快堆满，队伍被迫停摆。 左杯只顾产生 Zn²⁺（堆积正电荷），右杯只顾消耗 Cu²⁺（剩下多余的负离子）， 电荷账目两边都不平衡，反应瞬间"刹车"。盐桥就是那条"清货通道"， 让两边的电荷账实时结清，搬运才能一直进行。

LEVEL 2 · 标准

电子走导线（外电路），但溶液里没有自由电子，溶液导电全靠离子（内电路）。 若两杯互不相通：负极区 Zn²⁺ 越积越多、正极区 SO₄²⁻ 相对过剩，短短一瞬间 积累的电势差就足以反向抵消化学推动力，电流在毫秒级停摆。接上充满 KCl 凝胶的盐桥后： K⁺ 迁向阴极区补正电荷缺口，Cl⁻ 迁向阳极区中和多余的 Zn²⁺， 两杯保持电中性，电流持续。盐桥还顺带拦住 Cu²⁺ 跑去锌极直接反应，避免化学短路。

LEVEL 3 · 本质

一个完整的电池回路 = 电子导体（金属导线）+ 离子导体（溶液与盐桥）串联， 两种电流在电极表面"换乘"：负极把电子交给导线、把离子留给溶液；正极反之。 盐桥选用 KCl 而非任意盐，是因为 K⁺ 与 Cl⁻ 迁移速率几乎相同， 可把两溶液界面上的液接电势压到最小，不让它偷走电池的电压。 精密测量中甚至用"盐桥链"逐级过渡——电化学的工程学，一半都在跟界面较劲。

想一想：用一根粗铜丝代替盐桥，两头分别浸进两杯溶液，电池能工作吗？

提示：溶液里的"电流"由什么粒子搬运？铜丝里呢？

不能正常工作。铜丝是电子导体，而溶液中电子无法自由迁移—— 内电路需要的是离子通道。铜丝一插入溶液，自身立刻变成新电极， 引发副反应与额外的界面电势，电池电压被搅乱。盐桥的关键不在"导电"二字， 而在"以离子的方式导电"。

§3 电极电势：反应方向的预测学

锌"乐意"失电子、铜"不乐意"——这种差异可以量化。给每个电对 （氧化型/还原型，如 Cu²⁺/Cu）规定一个标准电极电势 standard electrode potential, E°：以标准氢电极（SHE）为 0 V 参照， 在离子浓度 1 mol/L、25 °C 下测得。几个常用值：

电对E° / V脾气
Zn²⁺ / Zn−0.76还原型 Zn 很慷慨，容易失电子（活泼金属）
Fe²⁺ / Fe−0.44铁也愿意失电子，但比锌矜持
Cu²⁺ / Cu+0.34氧化型 Cu²⁺ 有抢电子的胃口
Cl₂ / Cl⁻+1.36Cl₂ 是强氧化剂，抢电子胃口极大

排序思想一句话：E° 越大，其氧化型越强（越容易得电子）；E° 越小，其还原型越强（越容易失电子）。 把两个电对组成电池，判断方向只需三步（见下例），判据是 E°电池 = E°正 − E°负 > 0 则反应自发。 它与第一章 ΔG 判据心心相通：ΔG° = −nFE°， E° 为正时 ΔG° 必为负——电化学其实是热力学的"电压口音"。

能斯特方程：浓度让电压"打折扣"

标准电势对应 1 mol/L 的理想浓度。真实浓度偏离时，电势按 能斯特方程Nernst equation修正：

E = E° + (RT/nF)·ln([氧化型]/[还原型])

定性读法只有两条：氧化型浓度↑ → E 升；还原型浓度↑ → E 降。 用它解释电池的"衰老"：放电时负极区 Zn²⁺ 越积越多，E负 升高； 正极区 Cu²⁺ 越用越少，E正 降低。两头夹击， E电池 = E正 − E负 持续缩小，电压一路走低—— 手机用久了电量"跳水"，就是能斯特方程在记账。

📐 例题脚手架：用电势表判断反应方向

例 1 · 完整示范（看我做）
已知 E°(Zn²⁺/Zn) = −0.76 V，E°(Cu²⁺/Cu) = +0.34 V，E°(Fe²⁺/Fe) = −0.44 V。 (1) 判断 Zn + Cu²⁺ → Zn²⁺ + Cu 能否自发；(2) 判断 Fe + Zn²⁺ → Fe²⁺ + Zn 能否自发。
  1. 找两个电对，比大小：(1) 涉及 Zn²⁺/Zn（−0.76）与 Cu²⁺/Cu（+0.34）。 规则：E° 大的电对其氧化型当氧化剂（得电子，作正极）；E° 小的电对其还原型当还原剂（失电子，作负极）。 这里 Cu²⁺ 得电子、Zn 失电子——恰是题目写的方向。
  2. 算电池电动势：E°电池 = E°正 − E°负 = 0.34 − (−0.76) = +1.10 V。E° > 0 → 自发， 这正是 §2 丹尼尔电池的电压。
  3. 热力学互证：ΔG° = −nFE° = −2 × 96485 × 1.10 ≈ −212 kJ/mol < 0， 与第一章"ΔG < 0 自发"完全一致——电势判据和自由能判据是同一枚硬币的两面。
  4. (2) Fe + Zn²⁺：若按所写方向，正极应是 Zn²⁺/Zn（−0.76），负极 Fe²⁺/Fe（−0.44）， E°电池 = −0.76 − (−0.44) = −0.32 V < 0 → 不自发； 逆反应（Zn + Fe²⁺）才自发。✅ 检验直觉：锌比铁活泼，当然是锌失电子，方向判据与金属活动顺序表吻合。
⚠️ 误区粉碎机 · 电池里装的是电子？
✗
误区 "电池就像蓄水池，里面存着满满的电子；充电就是把电子灌回去，用完了就空了。"
✓
正确 电池里储存的是化学能——高能量的活性物质（锌与铜离子、锂与层状氧化物）。 电子只是流动的载体：放电时它们从负极经外电路涌向正极，在回路中循环流动、 数量从不增减；真正被消耗的是"愿意失电子"的物质。 充电也不是灌电子，而是用外电源把反应逆向推回去，重新生成高能物质—— 能量以化学形式归仓。

§4 电解与法拉第定律：逆天改命

原电池利用自发反应发电；电解electrolysis则反过来： 用外电源强行推动不自发反应（ΔG > 0）。电解池接电源正极的电极发生氧化（称阳极）， 接电源负极的电极发生还原（称阴极）——注意与原电池相反：

阳极（氧化）阴极（还原）
原电池（自发，发电）负极（如 Zn）正极（如 Cu）
电解池（非自发，耗电）接电源正极接电源负极
⚠️ 误区粉碎机 · 阳极 = 正极？
✗
误区 "阳极就是正极、阴极就是负极，背一遍走天下。"
✓
正确 阳阴极按反应类型定义（阳氧化、阴还原），正负极按电势高低定义。 原电池里阳极恰是负极（Zn）；电解池里阳极接的才是正极。先问氧化还原，再问正负， 两套名字就永远不会张冠李戴。

法拉第定律：电量换物质的汇率表

1833 年法拉第发现：电极上析出（或溶解）的物质的量，与通过的电量严格成正比。 换算链条只有三步：

Q = I·t　→　 n(e⁻) = Q / F　→　 n(物质) = n(e⁻) / z

其中 法拉第常数Faraday constant F = 96485 C/mol，正是 1 mol 电子的总电量； z 是每个离子转移的电子数（Cu²⁺ → Cu 时 z = 2）。这条链是电镀、电解精炼铜、 氯碱工业的计量基础——工厂电镀槽里"通多少电、镀多少铜"，账算到小数点后。

⚠️ 电解计算两大坑
一是时间不化秒：I·t 里的 t 必须用秒（2.0 h = 7200 s），用小时直接乘就错一千倍量级； 二是忘记除以 z：Cu²⁺ 析出要 2 个电子，电量再多也只能折半算铜。 动笔前先写电极反应式，把 z 圈出来，两个坑都能绕开。

📐 例题脚手架：电镀铜的定量账本

例 2 · 引导练习（和我一起做）
电解精炼铜时，阴极通过 5.0 A 电流持续 2.0 小时。理论上析出多少克铜？ （M(Cu) = 64 g/mol，F = 96485 C/mol）
  1. 💡 先写阴极反应、圈出 z：Cu²⁺ + 2e⁻ → Cu，z = 2。 这一步同时决定了后面要"除以 2"。
  2. 💡 电量 Q = I·t = 5.0 A × (2.0 × 3600 s) = 3.6 × 10⁴ C。 小时先化秒，别偷懒。
  3. 💡 电子的物质的量 n(e⁻) = Q / F = 36000 / 96485 ≈ 0.373 mol。
  4. 💡 折算铜：n(Cu) = n(e⁻)/z = 0.373/2 ≈ 0.187 mol， m = 0.187 × 64 ≈ 12 g。 ✅ 自查：12 g 约一枚旧硬币的质量，用 5 A 电流镀 2 小时——数量级合理。 顺手记个生活换算：36000 C ≈ 10 Ah，正是一节小充电宝释放的三分之一电量。

§5 锂离子电池：一把摇椅的故事

1991 年索尼把锂离子电池推向市场，从此手机、笔记本、电动车一路狂奔。 它的核心机制是：正常工作时 Li⁺ 在两种“层状仓库”之间嵌入与脱出，不依赖金属锂的沉积—— 一边是石墨的碳层，一边是锂钴氧化物（LiCoO₂）的氧化物层。这个模型俗称"摇椅电池"：

放电·负极：LixC₆ → xLi⁺ + xe⁻ + 6C　 放电·正极：Li₁₋ₓCoO₂ + xLi⁺ + xe⁻ → LiCoO₂

把本章知识对号入座：放电时它是原电池（自发反应，E 高的 LiCoO₂ 作正极）， 充电时它是电解池（外电源做功，把 Li⁺ 逆势推回）； 电解液与隔膜扮演"盐桥"的角色——只放行 Li⁺、挡住电子。 你口袋里装的，正是丹尼尔电池思想的最精致传人。

想一想：冬天手机在户外掉电飞快、甚至自动关机，用本章哪个概念解释最顺？

提示：第二章说过温度对速率常数的指数效应；本章能斯特方程则管电压。

两条线一起用：低温让离子迁移和电极反应速率骤降（动力学的账，第二章）， 管理电路误判为"没电"；同时电池内阻升高、输出电压被拉低（能斯特与欧姆降的账）。 回到暖处，速率与电压恢复，电量常常又"涨"回来——它不是被冻掉的能量， 而是暂时取不出来的能量。

模型边界与参考

本章用石墨／LiCoO₂ 电池示意正常嵌入反应；实际电池也可能发生副反应。参见 NREL 等研究者关于电池衰退的综述：低温、较大电流等条件下的析锂。

🧺 本章小结

  • 氧化还原 = 电子转移：氧化数升高失电子（还原剂），降低得电子（氧化剂）。
  • 原电池把氧化、还原拆到两极：负极 = 阳极 = 氧化；电子经外电路从负到正， 溶液内靠离子导电。盐桥维持两杯电中性，无它电流瞬停。
  • E° 越大氧化型越强；判方向三步：找电对 → 比 E° → E°电池 = E°正 − E°负 > 0 自发， 与 ΔG° = −nFE° 等价。
  • 能斯特方程定性：氧化型浓度↑ E 升、还原型↑ E 降；放电中电压持续走低。
  • 电解用外电源推动非自发反应；阳极接正极。法拉第定律： Q = I·t → n(e⁻) = Q/F → n = n(e⁻)/z（F = 96485 C/mol）。
  • 锂离子电池 = 摇椅：放电是原电池、充电是电解，Li⁺ 正常在石墨与 LiCoO₂ 层间往返；过快充电等条件下可能发生析锂副反应。

化学热力学：变化的方向盘

撕开暖手宝，它会自己发热，从不"倒吸"你手心的热变凉；拧开硝酸铵运动冰袋，它吸热变凉， 也照样自动发生。一个放热、一个吸热，却都自发——可见"放热"并不是方向的最终裁判。 本章要找到那位真正的裁判：先学会给变化记账（内能与焓），再学会加总路径（盖斯定律）， 最后请出 ΔG = ΔH − TΔS，一锤定音地回答：这个变化，能不能自发？

导入：世界为什么有方向

热咖啡放在桌上总会凉，凉咖啡却从不会自己变热；香水开了瓶盖就飘满屋子， 却从不会自己乖乖回到瓶里；山涧的水一路向下，从不倒流回山顶。 物理学把这类"不用外界推动就能发生、且不能自动倒退"的变化叫作 自发过程spontaneous process。

化学家关心的问题更具体：一个化学反应，比如铁生锈、葡萄糖氧化、水变冰， 到底能不能自发？条件是什么？这个问题之所以值钱，是因为答案直接告诉我们： 电池能不能做成、石灰石要烧到多高温才能变成石灰、一个梦想中的合成路线是不是"物理上允许"。 本章分三步走：先弄清给谁记账（§1）、账本上的两条规则（§2、§3）， 最后请出裁判（§4）。

想一想：打开一瓶香水，分子很快散满全屋；可它们从不会自己回到瓶里。这两件事的"能量"差别大吗？真正的差别在哪？

提示：比较"所有分子都在瓶里"与"分子均匀铺满全屋"这两种排列方式，哪种的排列数目更多？

能量上两者几乎没差别——分子飞来飞去的动能并没有变。真正的差别是排列方式的多寡： "散布全屋"的实现方式数不清，"全体回瓶"只有寥寥几种。世界天然偏爱"实现方式更多"的状态， 这就是 §4 要量化的熵。方向感，很多时候不是能量给的，是"混乱度"给的。

§1 体系、环境与状态函数

记账之前先划定账本边界。被研究的那部分物质叫体系 system，体系之外的一切叫环境 surroundings。研究杯里的热水，热水是体系，杯、桌面、空气是环境； 做实验时，敞口烧杯里的反应体系可以与环境交换物质和能量，封闭的弹筒只能交换能量。 热力学关心的是两者之间交换了多少热与功。

体系的"家底"用一些只取决于当前状态的量来描述：温度、压强、体积，以及内能 U。这类量统称状态函数 state function——只看起点和终点，与经过什么路径无关。 而热 Q 和功 W 是 过程量：它们描述"怎么走"，同一段旅程换个走法，数值就不同。

想一想：从山顶酒店回到山脚停车场，坐缆车或步行下山。"海拔下降"和"消耗的体力"哪个像状态函数？

提示：换一种下山方式，哪个数字永远不变？

海拔下降只由起点与终点决定——坐缆车也好、翻山越岭也罢，都是 800 米，它是"状态函数"。 消耗的体力却完全取决于路径长短与方式，它是"过程量"。热力学里： ΔU 像海拔差，Q 和 W 像体力——这解释了为什么同一反应在不同装置里放出的热可以不同， 而内能变化始终如一。

📌 一句话抓住重点
状态函数像海拔（只看起终点），过程量像脚程（要看路径）。 本章的主角——U、H、 S、G——全是状态函数， 所以它们的差值 ΔH、ΔG 才能像 §3 那样任意拆解、加减。

§2 热力学第一定律与焓

能量守恒写进化学账本，就是热力学第一定律 first law of thermodynamics：

ΔU = Q + W

采用常用符号约定：Q > 0 体系吸热，Q < 0 体系放热； W > 0 外界对体系做功，W < 0 体系对外界做功。 例：某气体吸热 50 J，同时膨胀对活塞做功 20 J，则 W = −20 J， ΔU = 50 + (−20) = +30 J——吸入的热，一部分变成了对外做的功，剩下的存进内能。 这条定律说：能量不生不灭，只在体系与环境之间转账；永动机不可能造出来。

焓：为"敞口容器"定制的能量账

实验室里的反应几乎都在恒压下进行（敞口容器，大气压不变）。 这时若有气体生成或消耗，体系要推挤大气做一笔"膨胀功"，ΔU 没把这笔账算清楚。 于是热力学定义了一个新状态函数——焓 enthalpy，H = U + pV， 它恰好补上这笔功，使得恒压过程的热收支变得干净利落：

恒压时 Qp = ΔH

这就是化学家开口闭口都是 ΔH 的原因：恒压下测到的"反应热"就是焓变。 符号一目了然：

符号含义体系能量手感例子（每摩尔）
ΔH < 0放热反应焓降低，多余的热跑到环境变热甲烷燃烧 −890 kJ；中和反应 −57.3 kJ
ΔH > 0吸热反应焓升高，从环境"借"热变凉冰融化 +6.0 kJ；硝酸铵溶于水 +25.8 kJ

注意"手感"一栏的暗雷：放热≠自发，吸热≠不自发——上表最后一行那个吸热却自动发生的溶解过程， 就是 §4 要解决的悬案。

§3 盖斯定律：反应热的加减法

盖斯定律指出：反应焓变只由始态与终态决定，与中间路径无关。 在只发生体积功的条件下，恒压反应热 qp = ΔH，恒容反应热 qv = ΔU；计算时须统一条件。 这就是盖斯定律 Hess's law。它其实是"ΔH 是状态函数的增量"这一身份的直接推论—— 既然只看起终点，那么方程式怎么加减，ΔH 就怎么加减，就像爬山的高度可以分段累加。

它最大的用处是把测不到的反应热算出来。有些反应无法"停在半路"， 比如碳不完全燃烧时常同时生成 CO 和 CO₂，难以直接准确测出只生成 CO 的反应焓，因此可以用盖斯定律绕路求解：

📐 例题脚手架：算出"C 烧成 CO"的 ΔH

例 1 · 完整示范（看我做）
已知 ① C(s) + O₂(g) → CO₂(g)，ΔH₁ = −393.5 kJ/mol； ② CO(g) + ½O₂(g) → CO₂(g)，ΔH₂ = −283.0 kJ/mol。 求 C(s) + ½O₂(g) → CO(g) 的 ΔH。
  1. 认清困境：碳在氧气里燃烧无法停留在 CO 这一步（生成的 CO 会立刻继续氧化）， 所以目标反应的 ΔH无法直接测量——这正是盖斯定律登场的信号。
  2. 设计路径：目标 = ① − ②。检查物质账： ①的 C + O₂ + CO₂ 减去 ②的 CO + ½O₂ + CO₂， CO₂ 两侧恰好消去，O₂ 剩 1 − ½ = ½，得到 C + ½O₂ → CO ✓ 正是目标。
  3. ΔH 同步运算：ΔH = ΔH₁ − ΔH₂ = (−393.5) − (−283.0) = −110.5 kJ/mol。注意"减去一个负数"等于加上它的绝对值，符号别丢。
  4. 合理性检验：C → CO₂ 放 393.5 kJ，其中 C → CO 放 110.5、CO → CO₂ 放 283.0， 110.5 + 283.0 = 393.5 ✓ 两条路"高度差"严丝合缝。答案：ΔH = −110.5 kJ/mol（放热）。

§4 熵与吉布斯自由能：方向的最终裁判

熵：世界的另一个偏好

新买的一副扑克牌按花色排得整整齐齐，洗几次就乱；把它撒在地上，永远不会自动码回原样。 分子世界也一样：冰的晶格里每个水分子都"站好队"，融化成水后各自游走，排列方式暴增。 热力学用熵entropy, S度量这种 "实现方式的多寡"——直观地说，熵是体系混乱度（更严格地说：微观状态数）的量度， S 越大，可能的微观排列越多。气体膨胀、物质溶解、晶体熔化，熵都在增大。

ΔG：两位裁判合成一位

现在把两股驱动力放进同一个公式。1870 年代，吉布斯定义了 吉布斯自由能Gibbs free energy, G， 并证明在恒温恒压条件下：

ΔG = ΔH − TΔS

ΔH 是能量项（放热为负，推动反应），TΔS 是熵项 （熵增为正、温度越高推力越大）。两者拔河，净推力就是 ΔG：

📌 自发性判据（恒温恒压）
ΔG < 0 正反应自发； ΔG = 0 达到平衡； ΔG > 0 正反应不自发（逆反应自发）。 冰融化的悬案就此告破：ΔH = +6.0 kJ/mol 在"反对"，但 298 K 时 TΔS ≈ 6.6 kJ/mol 在"推动"， ΔG = 6.0 − 6.6 = −0.6 kJ/mol < 0——熵赢了，所以吸热照样自发。

把 ΔH 与 ΔS 的四种正负组合摆成一张表，温度的角色一目了然：

ΔHΔSΔG 随温度自发性实例
−+恒为负任何温度都自发H₂O₂ 分解：2H₂O₂ → 2H₂O + O₂（放热又产气）
+−恒为正任何温度都不自发CO 分解回 C + ½O₂（例 1 的逆反应）
−−随 T 升高而增大低温自发，高温不自发（转折 T = ΔH/ΔS）合成氨 N₂ + 3H₂ → 2NH₃
++随 T 升高而减小高温自发，低温不自发（转折 T = ΔH/ΔS）CaCO₃ 分解 → CaO + CO₂
🪜 三级阶梯 · "能量最低"为什么不是自发的充分条件？
LEVEL 1 · 类比

世界不只有"往低处流"一个偏好，还有"越洗越乱"的偏好。瀑布奔向低处（能量降低）， 香水散向全屋（混乱度增大）——两股潮流常同向，让我们误以为"能量最低=必自发"。 冰在室温融化却逆流而上：它吸热、能量升高，但分子从整齐晶格获得自由， 混乱度的赢面盖过了能量的输面。只看能量，你就只看懂了半张地图。

LEVEL 2 · 数据

用公式算账。冰融化：ΔH = +6.0 kJ/mol，ΔS = +22 J/(mol·K) = +0.022 kJ/(mol·K)。 298 K（25 °C）时 ΔG = 6.0 − 298×0.022 = 6.0 − 6.6 = −0.6 kJ/mol，自发； 268 K（−5 °C）时 ΔG = 6.0 − 5.9 = +0.1 kJ/mol，不自发，冰稳稳不化。 转折点恰在 T* = ΔH/ΔS = 6000/22 ≈ 273 K——就是 0 °C。 同一个反应，温度改判：这正是"能量最低"无法解释、ΔG 才能解释的现象。

LEVEL 3 · 本质

真正的裁判是热力学第二定律：孤立体系的总熵永不减少。 体系融化吸热 ΔH，环境就失去这些热，环境的熵变 ΔS环 = −ΔH/T（负号：环境放热给体系）。 于是宇宙总熵变 ΔS总 = ΔS − ΔH/T。两边同乘 −T： −TΔS总 = ΔH − TΔS = ΔG。 所以 ΔG < 0 ⇔ ΔS总 > 0——ΔG 不过是把"环境那半本账"折算进体系的记账方式， 它的判决书落款永远是：宇宙总熵增加。

🔬 动手玩：ΔG 探索器

拖动 ΔH、ΔS、T 三个滑块，右侧实时显示 ΔG 数值与自发性判决，左侧四象限图上, 光点标出你当前的 (ΔH, ΔS) 位置与所在象限。试试三个预设：先用"冰融化"验证 273 K 转折， 再用"合成氨"体会"低温有利"为什么配低温工业条件，最后用"CaCO₃ 分解"把温度拉过 1113 K， 看判决当场翻转。

⚠️ 单位陷阱（本章头号丢分点）
ΔH 通常以 kJ/mol 计，ΔS 通常以 J/(mol·K) 计。 代入 ΔG = ΔH − TΔS 前必须统一：把 ΔS 除以 1000。 若拿 160.5 J 直接乘 298 K，TΔS 会凭空大出一千倍，"不自发"瞬间变成"自发"—— 一个单位，判决反转。动笔第一步永远先换算。
⚠️ 误区粉碎机 · 放热与自发
✗
误区 判断反应能否自发，看它放热还是吸热就行：放热的都能自发，吸热的都不能。
✓
正确 只看 ΔH 就只看了一半。冰融化（ΔH = +6.0 kJ/mol）和硝酸铵溶于水（ΔH = +25.8 kJ/mol， 试管摸上去冰凉）都吸热却自发，因为熵增项 TΔS 更大； 反之，放热若伴随剧烈熵减（如极高温下的合成氨），ΔG 也能转正。 唯一裁判是 ΔG = ΔH − TΔS 是否小于零。

📐 例题脚手架：用 ΔG 判断分解能否发生

例 2 · 引导练习（和我一起做）
煅烧石灰石：CaCO₃(s) → CaO(s) + CO₂(g)， ΔH = +178.2 kJ/mol，ΔS = +160.5 J/(mol·K)。 (1) 判断 300 K 时能否自发；(2) 判断 1200 K 时能否自发；(3) 求转折温度，并解释石灰窑为何要烧到约 900 °C。 （每步都先给提示，自己算完再点开对照）
  1. 💡 第一步永远是把单位摆齐：ΔS = 160.5 J/(mol·K) ÷ 1000 = 0.1605 kJ/(mol·K)。ΔH 保持 kJ/mol，别动。
  2. 💡 300 K：ΔG = 178.2 − 300×0.1605 = 178.2 − 48.2 = +130.0 kJ/mol > 0， 常温下不自发——这就是山上的石灰岩亿万年不分解的原因。
  3. 💡 1200 K：ΔG = 178.2 − 1200×0.1605 = 178.2 − 192.6 = −14.4 kJ/mol < 0， 高温下自发。注意 ΔS > 0（产生了气体），TΔS 项随温度越涨越快，终于反超。
  4. 💡 转折温度 T* = ΔH/ΔS = 178.2/0.1605 ≈ 1110 K（约 837 °C）。 石灰窑烧到 900 °C 以上，正是为了跨过这道门槛并留出余量。 ✅ 自查：T* 介于 300 K 与 1200 K 之间，与 (1) 不自发、(2) 自发的结论自洽。
想一想：ΔG = 0 意味着反应"停住不动"了吗？

提示：回忆化学平衡里正、逆速率的关系。

没有"停住"。ΔG = 0 是平衡态：正、逆反应仍在时刻进行，只是速率相等， 宏观浓度不再变化。ΔG 像下坡的坡度：离平衡越远坡越陡（驱动力越大）， 到达谷底坡度归零——但分子层面的来往从不停止。这也提醒我们： ΔG 只管"往哪边走、走多远"，不管"走多快"。

⚠️ 误区粉碎机 · ΔG 负了就万事大吉？
✗
误区 只要算出 ΔG < 0，反应就会顺利发生，而且发生得很快。
✓
正确 热力学只回答"能不能、往哪边"，从不回答"多快"。 金刚石变成石墨 ΔG < 0，可你手上的钻戒安然无恙——因为速率慢到亿年为单位。 速率归动力学管，那是下一章的主角；工业上许多"ΔG 很负"的反应仍要靠高温与催化剂， 就是为了同时满足两章的要求。

🧺 本章小结

  • 划清体系与环境后记账：ΔU、H、S、G 都是状态函数（只看起终点），Q、W 是过程量。
  • 第一定律 ΔU = Q + W：能量守恒，永动机无门。
  • 恒压反应热即焓变：ΔH < 0 放热、ΔH > 0 吸热。
  • 盖斯定律：方程式怎么加减，ΔH 就怎么加减——测不到的反应热可以"绕路"算出。
  • 熵 S 度量混乱度；自发的唯一裁判是 ΔG = ΔH − TΔS（ΔG<0 自发，=0 平衡，>0 逆向自发）。
  • 四种 ΔH/ΔS 组合里，同号的两种存在转折温度 T* = ΔH/ΔS； 计算前务必统一单位（ΔS 除以 1000）。

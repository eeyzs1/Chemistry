物态与溶液：分子的群居生活

一个水分子无色无形；10²³ 个水分子聚在一起，才有了雨、雾、冰与海洋。 本章看两件事：温度与压强如何指挥粒子的"群居方式"（三态与气体定律）， 以及物质彼此溶解时如何记账（浓度与稀释）。化学反应大多发生在溶液里——这章是它们的后台。

导入：同一群演员，三种舞台剧

冰、水、水汽的分子一模一样，区别只在"演出方式"：冰里分子手拉手各就各位（固定队列）； 水里分子挤在一起还能换位（亲密但自由）；水汽里分子各自飞奔（互不打扰）。 指挥这场换戏的导演，是温度与压强。高压锅为什么做饭快？开汽水为什么"呲"一声？ 都能从本章找到答案。

想一想：为什么湿衣服在夏天比冬天干得快？

提示：蒸发 = 水分子挣脱液面的"越狱"，越狱需要什么？

分子挣脱液面需要足够的动能。温度越高，分子的平均动能越大， "够格越狱"的分子比例呈指数上升（这为 04 分支的玻尔兹曼分布埋下伏笔）。 所以夏天蒸发快、晾衣快，高压锅内温度高、反应快。

§1 三态：同一批分子，三种纪律

状态分子排列分子运动形状/体积生活例
固态规则紧密排列原地振动形状固定、体积固定冰、铁钉
液态紧密但无序振动 + 换位滑动形状随容器、体积固定水、水银
气态相距遥远高速直线飞行 + 碰撞形状体积都不定、充满容器水蒸气、空气

📌 温度 = 分子平均动能的度量
温度不是"热的多少"，而是分子无规则运动剧烈程度的统计量。 这一个视角统一解释了：蒸发加快、扩散加快、反应加快（04 分支动力学）、固体熔化——全是分子跑得更欢了。

§2 气体定律：被压缩的脾气

气体分子占容器绝大部分空间是"空"，所以气体最容易被压缩、也最容易定量描述。 两条经典规律（定量实验都出自 17–18 世纪）：

  • 玻义耳定律Boyle's law：温度不变时，pV = 常数——体积压一半，压强翻倍。
  • 查理定律Charles's law：压强不变时，V ∝ T（热力学温度）——温度升高，体积膨胀。

合并成一条万能公式——理想气体方程： pV = nRT（R = 8.314 J·mol⁻¹·K⁻¹，T 必须用开尔文温度 K = °C + 273.15）。

🔬 动手玩：注射器压缩实验

例 1 · 完整示范：标准状况下的气体体积
标准状况（0 °C、101.325 kPa）下，2 mol 理想气体占多大体积？
  1. 列已知量：n = 2 mol；T = 0 °C = 273.15 K（开尔文！）；p = 101.325 kPa = 101325 Pa。
  2. 理想气体方程变形：V = nRT / p。
  3. 代入：V = 2 × 8.314 × 273.15 ÷ 101325 ≈ 0.0448 m³ = 44.8 L。
  4. ✅ 结论：标况下 1 mol 任何理想气体 ≈ 22.4 L（气体摩尔体积），与气体种类无关——因为决定体积的只是分子个数与动能，不是"谁"。
⚠️ 误区粉碎机 · "0 °C 就是 0"
✗
误区 气体计算里直接把摄氏温度代入公式："T = 25 °C 就填 25"。
✓
正确 气体定律中的 T 是热力学温度（开尔文）：T/K = t/°C + 273.15。 0 °C 的分子动能并不为零——真正的"零动能"在 −273.15 °C（绝对零度）。 填摄氏温度会让查理定律彻底算错（V 与 T 成正比的比例基准就错了）。

§3 溶液与浓度：液态化学的记账本

溶液solution = 溶质（被溶解者）+ 溶剂（溶解者）。 糖水里糖是溶质、水是溶剂。描述"多浓"有三种常用语言：

表示法定义公式典型场景
物质的量浓度 c单位体积溶液中溶质的摩尔数c = n / V（mol/L）实验室试剂瓶标签
质量分数 w溶质质量占溶液质量的百分比w = m质 / m液 × 100%浓硫酸 98%、消毒酒精 75%
ppm（百万分之一）极稀浓度，mg/L（稀水溶液近似）1 ppm = 1 mg/L水质、空气质量报告
例 2 · 完整示范：配制溶液的用量计算
实验室要配制 250 mL 0.1 mol/L 的 NaCl 溶液，需称取氯化钠多少克？（M = 58.5）
  1. 统一单位：V = 250 mL = 0.250 L。
  2. 求溶质摩尔数：n = cV = 0.1 × 0.250 = 0.025 mol。
  3. 换算质量：m = nM = 0.025 × 58.5 = 1.46 g。
  4. ✅ 操作：称 1.46 g NaCl → 溶于少量水 → 转移到 250 mL 容量瓶定容。注意是"最终体积 250 mL"，不是"加 250 mL 水"。
例 3 · 引导练习：稀释（和我一起做）
把 100 mL 2 mol/L 的盐酸稀释成 500 mL，稀释后浓度是多少？
  1. 💡 稀释前后什么不变？——溶质的摩尔数不变（加盐酸没加酸，只加了水）。
  2. 💡 写出守恒式 c₁V₁ = c₂V₂ → 2 × 100 = c₂ × 500。
  3. 💡 解得 c₂ = 0.4 mol/L。体积变 5 倍，浓度变 1/5。
  4. ✅ 自查：n = 0.2 mol 不变；0.2 ÷ 0.5 = 0.4 ✓。
⚠️ 误区粉碎机 · 饱和 ≠ 浓
✗
误区"这杯溶液饱和了，所以它一定很浓。"
✓
正确 饱和只说明该温度下溶质溶解到上限，上限本身可高可低： 饱和的蔗糖水浓得发腻，而饱和的氢氧化钙（石灰水）稀到 0.02 mol/L 以下。 "饱和"是相对溶解度的概念，"浓稀"是绝对浓度的概念，两码事。
想一想：打开汽水瓶盖为什么会涌出气泡？

提示：瓶盖未开时瓶内压强比大气大多少？气体溶解度与压强有什么关系？

灌装时用 2–4 个大气压的二氧化碳"压"进汽水——压强越大，气体溶解度越大（亨利定律）。 开盖瞬间压强跌回 1 atm，溶解度上限骤降，多余的 CO₂ 必须析出，于是形成气泡涌出。 摇晃会加速析出（更多成核点），所以摇晃过的汽水开盖更猛——开汽水先静置，是化学常识。

🧺 本章小结

  • 三态的本质是分子排列与运动纪律的差异；温度是平均动能的度量。
  • 气体两定律 → 理想气体方程 pV = nRT；T 用开尔文；标况摩尔体积 22.4 L/mol。
  • 浓度三语言：c = n/V（实验室）、质量分数（工业）、ppm（环境痕量）。
  • 稀释的守恒是溶质摩尔数不变：c₁V₁ = c₂V₂。
  • 饱和 ≠ 浓；气体溶解度随压强升高（亨利定律——汽水的秘密）。

仪器分析三剑客：光谱、色谱与质谱

新房装修后测甲醛、果蔬查农残、运动员尿检兴奋剂——目标物含量常在百万分之一以下， 滴定的"体积尺子"在这里完全失效。现代分析实验室靠三件武器打天下： 光谱让分子"亮出身份牌"（吸收什么光、吸收多少），色谱把混在一起的分子 "排队分开"，质谱给每个分子"称重并读出同位素签名"。本章把三剑客一次讲透， 并回答一个贯穿全章的问题：仪器直接给我们的究竟是信号，还是答案？

导入：百万分之一的世界

国家标准规定生活饮用水硝酸盐限值 10 mg/L、铅限值 0.01 mg/L——后者相当于在一个标准泳池里 溶进一枚回形针。靠滴定？消耗的滴定剂体积连滴定管的刻度都读不出来。 进入痕量与超痕量的世界，分析化学家换上了仪器时代的兵器谱： 把光打进样品看它吸收什么（光谱学），把混合物塞进一根管子让它自己排队（色谱学）， 再把每个分子打成离子逐个称重（质谱）。

但无论仪器多贵、屏幕多炫，有一条第 1 章立下的铁律在本章反复出现： 仪器输出的是信号，不是浓度——把信号换算成答案，永远要靠"用已知换未知"的校准。 带着这句话，我们登台三剑客。

§1 光谱分析：紫外-可见与朗伯-比尔定律

光谱学spectroscopy研究光与物质的相互作用。 分子只能吸收特定能量的光子（能量 = hν，恰好等于两个能级之差）， 于是"吸收哪些波长、吸收多少"就成了分子的身份证与体重秤。 最常用的入口是紫外-可见吸收光谱UV-Vis： 让一束单色光穿过样品池，比较进出的光强。

定义透射比transmittance T = I / I₀（出射光强与入射光强之比）， 吸光度absorbance A = −lg T = lg(I₀/I)。1852 年，比尔与朗伯发现： 稀溶液的吸光度与浓度、光程成正比——

A = ε·b·c　（朗伯-比尔定律Lambert-Beer law）

符号含义单位备注
A吸光度无量纲与浓度线性，实用范围 0.2–0.8 最佳
ε摩尔吸光系数L·mol⁻¹·cm⁻¹物质在特定波长的"吸收本领"，强生色团可达 10⁴–10⁵
b比色皿光程cm常用 1.00 cm，加厚一倍 A 翻倍
c溶液浓度mol/L稀溶液范围内成立，过浓会弯曲

为什么费劲定义 A 而不直接用透射比？因为 T 与 c 是指数衰减关系（浓度翻倍、光强指数级变暗）， 画出来是弯的；取对数后的 A 与 c 是直线——好画线、好拟合、好反查。 下面的比色皿随浓度变深，注意出射光束同时变暗，而 A 读数线性增长：

🔬 动手玩：比尔定律滑块

例 1 · 完整示范（看我做）：由吸光度求浓度
某有色溶液在 1.00 cm 比色皿中、指定波长下测得吸光度 A = 0.420。 该物质在此波长下的摩尔吸光系数 ε = 4.2×10³ L·mol⁻¹·cm⁻¹。求浓度。
  1. 变形公式：由 A = εbc 得 c = A / (ε·b)。
  2. 代入：c = 0.420 / (4.2×10³ × 1.00) = 1.0×10⁻⁴ mol/L。
  3. 检查量程：A = 0.42 落在最佳区间 0.2–0.8 内，读数可靠；若 A 太小应加大比色皿光程或浓缩，A 太大应稀释。
  4. ✅ 有效数字自查：A 三位、ε 两位 → 结果两位：c = 1.0×10⁻⁴ mol/L。
例 2 · 引导练习（和我一起做）：标准曲线反查
用分光光度法测水中铁：配制系列标准溶液，测得 c = 2/4/6/8 mg/L 对应 A = 0.12/0.24/0.36/0.48。相同条件下测得未知水样 A = 0.33。 求水样含铁量。（提示藏在每一步里，先自己想想再点开）
  1. 💡 先验线性：A/c = 0.12/2 = 0.24/4 = 0.06（L/mg）处处相等 → 标准曲线是过原点的直线 A = 0.06c。
  2. 💡 反查浓度：c = A / 0.06 = 0.33 / 0.06 = 5.5 mg/L。
  3. 💡 检查范围：5.5 mg/L 落在标准系列 2–8 mg/L 之内——内插安全；若未知样超出标准范围，应稀释或扩展标准系列，绝不外推。
  4. ✅ 报告 5.5 mg/L（两位有效数字）。这正是第 1 章"标准曲线：用已知换未知"的仪器版实战。
⚠️ 误区粉碎机 · 高级仪器直接给出答案，无需校准？
✗
误区 花几十万买的仪器自带"mg/L"打印口，结果直接出——仪器够高级，就不需要标准曲线、 不需要内标，说明书都不用翻。
✓
正确 仪器输出的永远是信号（吸光度、峰面积、离子计数），不是浓度。 把信号换算成含量必须靠已知浓度的标准（外标曲线、内标、标准加入）；仪器会漂移、 检测器会老化、样品基体会干扰——"用已知换未知"的校准思想在第 1 章和本章一次都没变过。 打印口里那个浓度，也是仪器替你查了它内置的标准曲线而已。
想一想：两杯同样浓度的蓝色溶液，一杯光程 1 cm、一杯 2 cm，哪杯更蓝？透过的光呢？

提示：光每穿过 1 cm，都被"吃掉"同样比例——按比例衰减意味着什么关系？

2 cm 那杯更蓝。光强按指数衰减：每穿过 1 cm 被吸收固定比例， 所以 I = I₀·10−kbc——这就是"朗伯"那半边定律（A 与 b 成正比）的来源； "比尔"那半边则说浓度 c 也以同样的方式起作用。二者相乘，才有 A = εbc 的简洁线性。

§2 红外"指纹区"与原子吸收：光谱的另外两副面孔

红外光谱：官能团的实验探测器

把波长换成红外光（4000–400 cm⁻¹），分子不再发生电子跃迁，而是振动被激发—— 原子团像用弹簧连接的小球，每种键有自己的"固有频率"，只吸收频率匹配的红外光子。 于是红外光谱（IR）直接把官能团functional group 摆上台面（在 02 有机化学里你认识了它们的反应性格，IR 则负责"点名"）：

官能团特征吸收 / cm⁻¹峰形印象
O—H（醇、酚、水）3200–3600又宽又圆的"大馒头"
N—H（胺、酰胺）3300–3500中等强度、稍尖
C—H2850–3000一组小尖峰
C=O（酮、醛、酸、酯、酰胺）1650–1750窄而强，全谱最醒目的峰
C—O（醚、醇）1000–1300较强

高波数段（4000–1300 cm⁻¹）像"官能团公告栏"；低波数段（1300–400 cm⁻¹）则是 指纹区fingerprint region——整分子各种振动的大合奏， 分子结构哪怕只差一个甲基，整段图谱就面目全非。把样品谱图与标准谱库比对， 像警方核对指纹一样确认"正是这个化合物"——这就是"指纹区"名号的由来。

原子吸收光谱（AAS）：一句话认识

想测痕量金属（铅、镉、铜、锌）？把样品气化成基态原子蒸气， 用该元素的空心阴极灯发出特征谱线穿过蒸气——基态原子最"挑食"，只吃自己波长的那一口， 吸光度同样与原子浓度成正比。AAS 灵敏度高、选择性好，是水质与食品中重金属的经典筛查手段。

想一想：丁醇与乙醚组成相同（C₄H₁₀O），只用一张红外谱就能区分它们吗？

提示：两者的差别在官能团——O 的旁边连着什么？哪个官能团有"招牌峰"？

能，而且一步到位。丁醇有 O—H：3200–3600 cm⁻¹ 的宽峰 + 1000–1100 cm⁻¹ 的 C—O 峰； 乙醚只有 C—O 而没有 O—H。看一眼"官能团公告栏"就能分家——这正是 IR 相对其他手段的独门优势： 直接点名官能团。再往指纹区核对，还能确认具体是哪一种同分异构体。

§3 色谱：先分离，后检测

光谱有个软肋：遇到混合物，各组分的光谱彼此叠加，像十几个人同时抢话筒。 色谱chromatography的答案是先分离、后检测： 让混合物随流动相mobile phase流过一层 固定相stationary phase， 各组分在两相间"进进出出"的偏好不同，宏观上表现为迁移速度不同—— 于是同一起点出发的它们，会在柱子尽头分批到达，形成一个个独立的色谱峰。

🪜 三级阶梯 · 色谱为什么能"分开"本来混在一起的物质？
LEVEL 1 · 类比

把色谱柱想成一条洒满商铺的长街，流动相是推着人走的人流。三种行人同时出发： 逛店欲为零的从头走到尾；见店就进的走几步停半天；介于两者之间的偶尔进店。 走出街口时，他们自然分成了三批——爱"待在固定相里"的组分，永远最后到达。

LEVEL 2 · 数据

量化"爱待在固定相"的指标是分配系数partition coefficient K = c(固定相) / c(流动相)。K 大的组分大部分时间滞留在固定相里， 平均迁移速度小；K 小的随流动相一路畅行。柱子足够长时，速度差累积成时间差—— 每个组分在自己的保留时间retention time, tR 流出：同一条件下 tR 是组分的"时间指纹"（定性依据）， 而峰面积与该组分含量成正比（定量依据，仍要靠标准曲线换算）。

LEVEL 3 · 本质

分离的好坏用分离度 R = 2(tR2−tR1)/(w₁+w₂) 衡量：峰既要"离得远"又要"长得窄"。峰会展宽，因为分子在柱内有三种扩散来源—— 涡流扩散（路径长短不一）、纵向分子扩散、两相间传质阻力（van Deemter 方程描述三者的总和效应）。 柱效用理论塔板数 N 表征。选多长的柱、多细的填料、多快的流速， 本质都是在与这三种展宽赛跑——这是色谱方法开发的全部艺术。

🔬 动手玩：色谱分离动画

色谱两大家族按流动相分：气相色谱GC用载气， 高效液相色谱HPLC用液体（高压驱动）。选择一句口诀： 能气化、耐热的用 GC（快、灵、省）；不能气化、怕热的用 HPLC（几乎万能）。

气相色谱 GC高效液相色谱 HPLC
流动相载气（He、N₂）液体（水/甲醇/乙腈等，高压泵驱动）
样品要求能气化、热稳定可溶于流动相即可，不怕热敏、大分子
典型任务白酒风味、溶剂残留、油气组成、兴奋剂初筛药物、氨基酸、维生素、食品添加剂、蛋白质
📌 一句话抓住重点
色谱的革命在"分离"二字：它把"混合物的定量"转化为"纯组分信号的测量"。 保留时间定性、峰面积定量——两句话撑起了现代分析实验室的半壁江山； 色谱与质谱联用（GC-MS、LC-MS）后，更是定性定量一肩挑。

§4 质谱：给分子称重，读同位素签名

质谱mass spectrometry, MS的思路干脆利落： 把样品分子电离成离子（常用高能电子把分子打掉一个电子，得到带正电的分子离子）， 再利用电场与磁场让离子按荷质比mass-to-charge ratio, m/z （离子质量与所带电荷数之比）分道扬镳，检测器逐个计数——得到一张以 m/z 为横轴的"棒图"。

读图三步：最高质量端寻找分子离子峰 molecular ion peak——它的 m/z 就是相对分子质量（M）； 碎片峰看断裂规律，推断官能团与骨架连接（与 IR、核磁联用更稳）； 同位素峰则是元素组成的铁证——这里正是 00 总论第 1 章"同位素"的用武之地： MS 的分辨率足以把质量相差 1–2 的同位素离子分成相邻的峰。

最实用的两条同位素判据：

  • 含一个 Cl：³⁵Cl 与 ³⁷Cl 天然丰度约 75.8% : 24.2% ≈ 3 : 1， 谱图上 M 峰与 M+2 峰强度比约 3:1。
  • 含一个 Br：⁷⁹Br 与 ⁸¹Br 各约 50%，M 与 M+2 等高双峰，一眼可辨。

碳的 ¹³C（约 1.1%）则在 M+1 处留下一枚与碳原子数成正比的小峰。 三剑客至此合体：光谱认官能团、色谱做分离、质谱定分子—— 联用仪器（GC-MS、LC-MS）加上化学计量学的数据处理，就是导学页"子分支地图"里那片更远的疆域。

想一想：某卤代烃的质谱中，m/z 128 与 130 两峰强度比约为 3:1。它含什么元素？若换成 1:1 呢？

提示：回想 00 总论——氯和溴各自有哪些天然同位素？丰度比例是多少？

3:1 的 M / M+2 双峰是一个氯原子的签名（³⁵Cl 约 75.8%、³⁷Cl 约 24.2%）。 若是 1:1，则是一个溴原子（⁷⁹Br 与 ⁸¹Br 各约一半）。 不用做任何化学反应，一张质谱图就交出了元素组成的关键证据——这就是"同位素签名"的威力。

🧺 本章小结

  • UV-Vis：朗伯-比尔定律 A = εbc，A 与浓度线性、最佳区间 0.2–0.8；定量仍靠标准曲线反查。
  • IR：官能团区点名（O—H 宽峰、C=O 尖强峰等），指纹区与标准谱比对确认化合物；AAS 一句话——基态原子吃掉特征谱线，测痕量金属。
  • 色谱：分配系数差异 → 差速迁移 → 保留时间 tR 定性、峰面积定量；能气化用 GC，怕热大分子用 HPLC。
  • 质谱：按 m/z 分离，分子离子峰给相对分子质量，碎片峰推结构，同位素峰辨元素（Cl 3:1、Br 1:1）。
  • 铁律不变：仪器给的是信号，不是答案——所有定量都要"用已知换未知"的校准。
  • 三剑客联手（GC-MS / LC-MS）＋化学计量学，构成现代分析实验室的主力与子分支地图的下一站。

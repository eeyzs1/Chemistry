# 🧪 Chemistry · 化学自学中心

一个完全离线、交互式的化学学习资料库。每个主分支一个文件夹，每章一份交互式 HTML 教材——概念用动画、图示和自测题来讲，双击即用，无需联网。

## 一、化学的分支地图

化学传统上以 **“五大化学”** 为骨架（国内外化学院的课程体系基本如此），在此之上生长出大量交叉与专门分支。本资料库为每个主分支建立了独立文件夹。

|---|--------|----------|----------|--------------------|--------|

### 3. 更细的子分支归属速查

学了主分支之后，这些“更细的方向”都有迹可循：

- **电化学** → 物理化学（电池、电解、腐蚀）
- **光谱学 / 色谱学** → 分析化学（紫外、红外、核磁、气质联用）
- **立体化学** → 有机化学（手性与构象）
- **配位化学** → 无机化学（配合物与中心金属）
- **表面与界面化学** → 物理化学（催化、吸附）
- **化学生物学** → 生物化学（用化学探针研究生命）
- **蛋白质工程 / 酶工程** → 生物化学
- **纳米化学** → 材料化学
- **绿色化学** → 环境化学（更环保的合成与过程）
- **量子化学** → 理论与计算化学 / 物理化学

## 四、教材怎么用

1. **打开方式**：双击任意 `index.html`（或章节文件）即可在浏览器中阅读，完全离线，无需服务器。
2. **每一章都内置这些组件**：
   - 🪜 **三级讲解阶梯**：`直觉理解 → 标准讲解 → 深入原理`，同一概念按你能接受的深度切换，随时升降级；
   - ⚠️ **误区粉碎机**：列出该话题最常见的错误认知，并给出正确图景；
   - 🪜 **例题脚手架**：完整示范 → 带提示的引导练习 → 独立练习（答案可展开），难度渐退式放手；
   - 💭 **思考提示**：苏格拉底式提问，先自己想，再点开对照；
   - 🎬 **交互动画/模拟**：轨道、滴定曲线、能量图、衰变等均可用按钮与滑块操作；
   - ✅ **章末自测**：即时判分 + 逐题解析。
3. **建议节奏**：一章 30–60 分钟；先看直觉级，能复述后再升到标准级；自测 80% 以上再进入下一章。
4. **学习进度**：章末自测的成绩会记录在浏览器本地（localStorage，不联网、不上传）。
   再次打开同一章会显示"历史最佳"；分支导学页的章节卡片会标注 ✓ 已通过（≥80%）或最近最佳成绩。
   清除浏览器数据即可重置进度。
5. **无障碍与省电**：全站尊重系统"减少动态效果"设置（动画改为静态结果展示）；
   常驻模拟动画只在画面可见且页面处于前台时运行，滚出视口即自动暂停。

- [teaching-resource-generator](https://skills.sh/partme-ai/full-stack-skills/teaching-resource-generator)（partme-ai/full-stack-skills）：需求分析 → 内容设计 → 格式优化的教材制作流程。

设计规范参考 [ui-ux-pro-max](https://www.skills.sh) 技能库的可访问性与排版准则（对比度 ≥ 4.5:1、16px 正文、1.7 行高、动画克制并尊重系统减弱动效设置）。
